BrokerDesk

A PHP & MySQL real estate management system for listing, browsing and managing property listings.

PHP ≥ 7.3 MySQL ≥ 5.7 PDO / GD extensions

About this page

BrokerDesk is a server-rendered PHP application backed by a MySQL database, so it can't run directly on GitHub Pages (which only serves static files). This page is a static overview of the project — to run the full application, follow the setup steps below on a PHP + MySQL stack such as XAMPP or WAMP.

Features

Property listings

Browse properties by location, view details, images and grid/list layouts.

User & admin roles

Two permission levels: regular users and admins who manage all data.

Submit & manage properties

Users can add, update and delete their own property submissions.

Loan calculator

Built-in EMI/loan calculator to help evaluate property affordability.

Run it locally

1. Install a PHP + MySQL stack (XAMPP / WAMP)
2. Import BROKERDESKMAIN/Database/developers.sql into a database named "developers"
3. Edit BROKERDESKMAIN/config.php with your DB credentials
4. Serve the repo root (index.php redirects to /dashboard/) or open
   BROKERDESKMAIN/index.php directly through your PHP server
